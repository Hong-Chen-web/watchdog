1. 背景与目标

前台原型(v0.6)已定版:macOS 深色仪表盘、九个可装配模块、Mole CLI 实时桥、中英双语。本说明书定义生产后台:SQLite 存储 + 模块化本地 HTTP 接口 + 两个既有数据源的接入管线。

设计原则:① 单机本地,零云依赖,数据不出设备;② 每模块一组接口,模块可拆装=接口可停用;③ 外部数据源(腾讯/新浪/东财/缠论/Mole)统一在后台收口,前台永远只认识 /api/*;④ 所有写操作幂等可重放。

2. 总体架构

关键决策:后台是独立本地 HTTP 服务而非 Tauri 内嵌命令,理由:① 开发期浏览器可直接调试(前台原型今天的形态无缝延续);② chan-monitor、Mole、server.js 三个既有进程都以 HTTP 形态存在,统一范式;③ 后端与 chan-monitor 同为 Python,行情拉取/容灾代码(push2 双域名、限流退避)直接复用。Tauri 壳负责窗口化与开机自启,退出时一并拉起/回收后台进程(sidecar 模式)。

3. 技术选型

层选型理由
桌面壳Tauri 2 + React内存/体积远优于 Electron;Wealthfolio 同路线;前台已是纯 Web
后台Python 3.11 + FastAPI + uvicorn(127.0.0.1:8790)与 chan-monitor 同栈,拉数模块整段复用;自动 OpenAPI 文档(/docs)即调试台
存储SQLite 3(WAL 模式)+ sqlite-migrate 风格自研迁移单文件、零运维、Time Machine 天然覆盖

系统监控Mole status-go --json 子进程已编译验证;作者官方预留的机器可读出口
前端数据层轮询(3s/60s)+ 预留 SSE单机场景轮询足够;SSE 接口在 v2 预留 text/event-stream

4. SQLite 数据模型

库文件:~/Library/Application Support/Workbench/workbench.db。所有时间戳存 ISO8601 本地时区字符串;金额存 REAL(元);日期存 YYYY-MM-DD。PRAGMA journal_mode=WAL; foreign_keys=ON;

CREATE TABLE module_config (
  module_id TEXT PRIMARY KEY,          -- portfolio/backtest/todo/ledger/market/sysmon/strategy/futures/calendar
  enabled   INTEGER NOT NULL DEFAULT 1,
  sort      INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT NOT NULL
);
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);  -- lang/theme/poll_interval 等 JSON 值

-- ① 待办
CREATE TABLE todos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,

-- ② 账本(对齐 Numbers"简单预算"模板)
CREATE TABLE ledger_categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,            -- 首次导入种子:娱乐/旅游·食物·房屋·医疗·个人物品·其他·旅行·人情
  name_en TEXT,
  color TEXT NOT NULL DEFAULT '#8e8e93',
  sort INTEGER NOT NULL DEFAULT 0
);
CREATE TABLE ledger_budgets (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  category_id INTEGER NOT NULL REFERENCES ledger_categories(id),
  year INTEGER NOT NULL,
  annual REAL NOT NULL DEFAULT 0,       -- Numbers「总年预算」列
  monthly REAL NOT NULL DEFAULT 0,      -- Numbers「单月预算」列
  UNIQUE(category_id, year)
);
CREATE TABLE ledger_entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,                   -- 交易日期
  payee TEXT,                           -- 商户/描述
  category_id INTEGER NOT NULL REFERENCES ledger_categories(id),
  amount REAL NOT NULL,                 -- 正=收入 负=支出(与 Numbers 金额列符号一致)
  note TEXT,
  source TEXT NOT NULL DEFAULT 'manual',  -- manual | numbers | chan(交易佣金自动记账)
  external_id TEXT UNIQUE,              -- numbers导入=sha1(date|payee|amount|category),幂等键
  created_at TEXT NOT NULL
);
CREATE INDEX idx_ledger_date ON ledger_entries(date);

-- ③ 行情 · 自选
CREATE TABLE watchlist (
  code TEXT PRIMARY KEY,                -- 000928
  name TEXT NOT NULL,
  note TEXT, sort INTEGER DEFAULT 0, added_at TEXT NOT NULL
);
CREATE TABLE quotes_cache (
  code TEXT PRIMARY KEY, name TEXT, price REAL, chg_pct REAL,
  updated_at TEXT NOT NULL
);
CREATE TABLE signals (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ts TEXT NOT NULL, code TEXT, name TEXT,
  kind TEXT NOT NULL,                   -- selection/exit/monitor/futures
  message TEXT NOT NULL, payload TEXT,  -- payload 为 JSON
  read INTEGER NOT NULL DEFAULT 0
);

-- ④ 持仓(镜像自 chan-monitor,后台拥有缓存副本)
CREATE TABLE chan_rounds (
  round_id TEXT PRIMARY KEY,            -- 缠论轮次 id/日期
  sel_date TEXT NOT NULL, raw TEXT NOT NULL, synced_at TEXT NOT NULL
);
CREATE TABLE holdings (
  code TEXT NOT NULL, round_id TEXT NOT NULL REFERENCES chan_rounds(round_id),
  name TEXT, buy_date TEXT, buy_price REAL, shares REAL,
  status TEXT NOT NULL DEFAULT 'holding',   -- holding/settled
  exit_date TEXT, exit_price REAL, exit_why TEXT,
  updated_at TEXT NOT NULL,
  PRIMARY KEY(code, round_id)
);
CREATE TABLE account_snapshots (   -- 资产曲线,每日 14:55 由后台落一档
  date TEXT PRIMARY KEY,
  cash REAL, market_value REAL, total REAL,
  source TEXT NOT NULL DEFAULT 'chan'
);

-- ⑤ 回测(归档导入为主)
CREATE TABLE backtest_runs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  created_at TEXT NOT NULL,
  label TEXT NOT NULL,                  -- "3成仓 2019-2026"
  params TEXT,                          -- JSON:BT_START/BT_CAPITAL/BT_FRACTION
  final_equity REAL, total_return REAL, trades INTEGER,
  win_rate REAL, pl_ratio REAL, worst_hit REAL
);
CREATE TABLE backtest_yearly (
  run_id INTEGER NOT NULL REFERENCES backtest_runs(id),
  year INTEGER NOT NULL, return_pct REAL NOT NULL,
  PRIMARY KEY(run_id, year)
);
CREATE TABLE backtest_curve (
  run_id INTEGER NOT NULL REFERENCES backtest_runs(id),
  seq INTEGER NOT NULL, date TEXT, equity REAL,
  PRIMARY KEY(run_id, seq)
);

-- ⑥ 系统监控(滚动 24h,夜间任务裁剪)
CREATE TABLE sysmon_samples (
  ts TEXT PRIMARY KEY,
  health INTEGER, cpu REAL, mem_pct REAL, net_rx REAL
);
-- ⑦ 同步审计
CREATE TABLE sync_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  source TEXT NOT NULL, status TEXT NOT NULL,  -- ok/fail/partial
  message TEXT, ts TEXT NOT NULL
);

6. 数据接入:Numbers 导入管线

触发:手动(设置页「从 Numbers 导入」)或 CLI;可重复执行,幂等。

.numbers 文件(iCloud 路径,含空格转义)
  │ ① JXA:osascript 驱动 Numbers 打开 → 每个 sheet export 为 CSV → 关闭(不落盘到原文件)
  ▼
CSV(交易表 + 年度预算表,存 $TMPDIR,导入完即焚)
  │ ② 解析:表头按模板识别(日期/商户/类别/金额;预算:类别/总年预算/单月预算)
  ▼
  │ ③ 类别映射:先精确匹配 ledger_categories.name;
  │    未匹配 → 返回 unmatched_categories,由用户在确认界面前缀选择映射后重放
  ▼
  │ ④ 幂等键:external_id = sha1(date|payee|amount|category)
  ▼
SQLite:INSERT OR IGNORE → ledger_entries / ledger_budgets / categories 种子
  ▼
⑤ 返回 {imported:n, skipped:n(重复), unmatched:[...]},写 sync_log

降级链:Numbers App 不在(命令行无 GUI 会话)→ 提示用户在 Numbers 手动「文件→导出→CSV」后走同一解析步骤(⑤ 之前完全一致)。Excel/CSV 手工导出路径是兜底,永远可用。

实测依据:文件为"简单预算"模板,类别 8 个(娱乐/旅游、食物、房屋、医疗、个人物品、其他、旅行、人情),预算页含总年预算/单月预算/实际支出/差额;交易表列以导入时实际表头核对为准,解析器按列名模糊识别(日期/时间→date,商户/描述→payee,类别→category,金额/数量→amount)。

7. 数据接入:chan-monitor 桥

工作台表来源(chan-monitor)同步策略
holdings / chan_roundsGET 8787/api/recommended/tail + /api/state60s 轮询 + 14:55 事件后立即拉;整轮 upsert(round_id 维度)

10. 错误模型与日志

HTTP 状态码:400 参数错 · 404 无资源 · 409 幂等冲突 · 502 外部源失败(chan/行情/Numbers)
响应体:{"error":{"code":"CHAN_UNREACHABLE","message":"chan-monitor 8787 不可达","stale":true}}
code 枚举:DB_ERROR / NUMBERS_EXPORT_FAILED / NUMBERS_UNMATCHED_CATEGORIES / CHAN_UNREACHABLE / QUOTE_TIMEOUT / MOLE_TIMEOUT

日志:结构化单行 JSON(ts/level/module/msg);sync_log 表记录每次外部同步结果,设置页可视化。
