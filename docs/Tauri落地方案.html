看门狗 Watchdog · Mac App 落地方案

v1.0 · 2026-10-05 · 承接《后台设计说明书 v1.0》M5 · 当前原型:design/index.html + server(FastAPI 8790)

1. 定位与现状盘点

当前一切均为原型阶段(前台单文件 HTML + 本地 FastAPI),但它已经是"半真半模拟"的高保真原型——数据库、接口、交互形态全部按生产设计实现。落地 Mac App 时,后端(含 SQLite schema、全部接口)原样复用,前台从单文件拆为模块化工程,外层加 Tauri 壳。

模块数据现状落地动作
待办 / 日志复盘真数据(SQLite)原样迁移
账本 / 预算 / 目标真数据(Numbers 导入 303 笔 + 目标 6 条)原样迁移;Numbers 导入做成 App 内按钮
回测档案真数据(1170 笔 + 93 点月度曲线)原样迁移
自选行情半真:添加/同步时拉一次腾讯快照,无定时轮动;三大指数为静态演示补 M3 快线:3s 轮询 + 双源容灾(复用缠论拉数代码)
持仓 / 资产曲线种子数据(9.23 轮三票 + 20 日曲线)chan-monitor 在线时代理覆盖;每日 14:55 资产快照落库
策略信号 / 期货 / 飞书 / 图表真数据(缠论 8787 只读桥,在线时)原样迁移;离线降级提示已有
系统监控 / 磁盘清理真数据(Mole status-go / analyze-go)两个 Go 二进制随 App 打包携带

2. 目标架构

┌──────────── Tauri 2 壳(Watchdog.app)────────────┐
│  Webview(React 前台 app/dist)                    │
│  Rust:窗口/托盘/开机自启/单实例/sidecar 管理       │
│         │ spawn/回收                              │
│  ┌────────────────────────────┐                  │
│  │ sidecar:watchdog-server     │ FastAPI          │
│  │ (PyInstaller 单目录打包)    │ 127.0.0.1:8790   │
│  │ SQLite + 全部 routers       │                  │
│  └────────────────────────────┘                  │
│  Resources:Mole status-go / analyze-go、          │
│            lightweight-charts.js、图标字体        │
└──────────────────────────────────────────────────┘
   外部(进程外,不强依赖):chan-monitor 8787、Numbers 文件、腾讯/新浪行情源

关键决策:后端保持独立本地 HTTP 服务(sidecar 化而非塞进 Rust),理由:①接口/数据库零改动,原型验证过的行为直接进生产;②浏览器可调试期长;③chan-monitor、Mole 本来就是进程外形态。App 退出时由 Rust 侧 kill sidecar。

3. 前台模块化迁移(design/index.html → app/src)

app/src/
  core/            # 从原型抽出的共享层
    store.js       #   装配/语言/视图(Zustand;localStorage 逻辑原样搬)
    i18n.js        #   双语字典(原 EN 对象整体迁移)
    api.js         #   API base(开发 8791 → 生产同源 sidecar)
    ui/            #   卡片骨架/圆环/弹层/装配目录/五组顶栏(现成组件化)
  modules/         # ★ 一个模块一个目录,与后端 router 一一对应
    todo/    {Card.jsx, api.js, i18n.js}
    ledger/  {Card.jsx, api.js, i18n.js}   # 明细手风琴/筛选/记一笔
    budget/  …  goals/ … journal/ …        # 预算环/目标三组/复盘三段式
    market/  …  portfolio/ … backtest/ … feishu/ …  # 含缠论图表弹层
    sysmon/  …  disk/ …                    # Mole 桥
  App.jsx          # 组视图路由(SEG_GROUPS 五组配置原样迁移)

迁移规则:每个模块的 HTML 结构、CSS、加载函数(loadXxx)整块搬进自己的目录,装配注册表 MODULES 由各模块自注册(core/store 汇总)——与后端 MODULE_ROUTERS 对称,真正实现"前后端同拆同装"。

4. 后端打包与数据迁移

事项方案
sidecar 打包pyinstaller --onedir main.py(纯 Python,无 cgo);产物改名 watchdog-server 放 src-tauri/binaries/,tauri.conf externalBin 声明
Go 依赖status-go、analyze-go 放 Resources/bin/,路径改为相对 App 资源目录(env WATCHDOG_HOME 注入)
数据目录~/Library/Application Support/Watchdog/(workbench.db 迁移脚本:首启检测旧 Workbench 目录则整体拷贝;端口/日志同目录)
图表静态件lightweight-charts.js 入 Resources,chan 路由读资源目录
缠论依赖不强绑:chan-monitor 仍独立运行(用户现有开机流程);App 检测 8787 在线则启用桥功能,离线显示降级态

5. Rust 壳要点

  • 窗口:1200×780 最小 960×600,深色 titlebar(windowEffects: sidebar 毛玻璃),记住位置
  • 托盘:菜单栏狗头图标 → 显示/退出 + 快捷看健康分/今日待办数(v2:HUD 弹窗)
  • 开机自启:tauri-plugin-autostart,设置页开关(settings 表已有键位)
  • 单实例:二次启动唤起已有窗口
  • sidecar 生命周期:启动等 /api/health 就绪再加载前端;退出 kill;崩溃自动拉起(复用看门狗之名)

6. 前置条件与风险

⚠ 前置:本机 Xcode 许可未同意,当前 brew/python3/cgo 全线受阻——编译 Rust/Tauri 前 must sudo xcodebuild -license accept(需用户亲自执行)。Go 工具链已在 /tmp/go(过期则重新下载 golang.google.cn)。
  • 无苹果开发者证书 → dmg 先 ad-hoc 签名(本机可用,分发时 Gatekeeper 需右键打开);后续可购证书公证
  • PyInstaller 体积 ~40MB + Go 二进制 10MB + 前端 → App 总体 <60MB,可接受
  • Python 版本:随 czsc-repo/.venv(3.12)冻结打包;升级走 App 更新通道(v2 updater)
